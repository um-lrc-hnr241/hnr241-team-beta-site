## Greenwood Community Garden website

A simple, accessible static website for Greenwood Community Garden, a fictional neighborhood garden club. Built with plain HTML/CSS/JS for GitHub Pages.

- `index.html` — Home page with welcome message, garden illustration, and how to join.
- `rules.html` — Plot rules for renting and maintaining a garden plot.
- `calendar.html` — Seasonal planting calendar.
- `styles.css` — Shared styles: leafy green and soft yellow accents on white, large readable text, tap-friendly navigation, high color contrast for accessibility (WCAG-conscious).
